# داده‌ها

فعلاً داده تجربی تولیدشده در پروژه وجود ندارد. جدول‌های مقاله‌ها باید از داده‌های اندازه‌گیری آینده جدا بمانند.

قالب [literature/extraction-template.csv](literature/extraction-template.csv) فقط سرستون دارد و دیتاست تکمیل‌شده نیست. هر ردیف آینده باید یک فرمول یا نتیجه با منبع، واحد و شرایط آزمون مشخص باشد. NR یعنی گزارش نشده؛ مقادیر مجهول تخمین زده نشوند. غلظت محلول پوشش، درصد نهایی پرکننده و درصد حجمی/وزنی جدا ثبت شوند.
